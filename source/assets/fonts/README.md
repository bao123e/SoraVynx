# Embedded UI fonts

Inter by The Inter Project Authors, SIL Open Font License 1.1 (OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/inter

These static TrueType instances were generated with fontTools from
Inter[opsz,wght].ttf at optical size 14 and weights 400, 600 and 700.
The private family names are SSTool UI, SSTool UI SemiBold and SSTool UI Bold
to avoid collisions with installed fonts and keep GDI weight selection explicit.
Character coverage is preserved, including Vietnamese. Fonts are registered
from DLL memory for this process only; SSTool does not install system fonts.
