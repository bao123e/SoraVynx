# SoraVynx UI fonts

Be Vietnam Pro, SIL OFL 1.1, from https://github.com/google/fonts/tree/main/ofl/bevietnampro.
Static Regular (400), SemiBold (600), Bold (700), with original Vietnamese glyph coverage.
Private GDI family names: SoraVynx UI, SoraVynx UI SemiBold, SoraVynx UI Bold.
Fonts are embedded and registered in the process; no system font installation.
OFL.txt contains the attribution and license.
